# 🐦 Flappy Bird Android App

A simple and fun **Flappy Bird Android game** where the player controls a bird and tries to pass through the pipes without hitting them.

The goal is to achieve the **highest score possible** by surviving as long as you can!

## 🎮 Features

- 🐦 Simple Flappy Bird gameplay
- 🎯 Score system
- 🏆 High score tracking
- 🚧 Random pipe obstacles
- 🔄 Restart game option
- 🎵 Game sound effects
- 📱 Android mobile-friendly interface
- ⚡ Smooth gameplay
- 🎨 Simple and attractive UI
- 📦 Android APK available

## 🕹️ How to Play

1. Open the Flappy Bird app.
2. Tap the screen to make the bird fly upward.
3. Avoid hitting the pipes.
4. Pass through the gaps between the pipes.
5. Each successful pipe gives you a score.
6. Try to beat your highest score!

## 🚀 Installation

### Method 1 — Android Studio

1. Download or clone this repository.
2. Open the project in **Android Studio**.
3. Wait for Gradle to finish syncing.
4. Connect an Android device or start an emulator.
5. Click **Run ▶**.
6. Install and play the game.

### Method 2 — APK

Download the APK from the **Releases** section of this repository.

Install the APK on your Android device and start playing.

## 🎯 Game Objective

The main objective is to survive as long as possible and achieve the highest score.

| Action     | Result         |
| ---------- | -------------- |
| Tap Screen | Bird Flaps     |
| Pass Pipe  | Score +1       |
| Hit Pipe   | Game Over      |
| Hit Ground | Game Over      |
| Restart    | Start New Game |

## 🏆 Scoring

The score increases whenever the bird successfully passes through a pair of pipes.

**Example:**

```text
Score: 10
Best Score: 25
```

Try to beat your previous high score!
