# 📦 ZIP Utility APK

A simple ZIP Utility Android application for managing ZIP files on mobile devices.

## ✨ Features
- Create ZIP archives
- Extract ZIP files
- Select files from device storage
- Download compressed files
- Simple and user-friendly interface
- Mobile-friendly design

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Android APK packaging

## 📱 Application Details
- **Project Name:** ZIP Utility
- **Platform:** Android
- **Application Type:** APK
- **Category:** File Management

## 📥 Download APK
Download the APK from the **GitHub Releases** section after the APK file has been uploaded.

## 🚀 How to Use
1. Install the APK on your Android device.
2. Open the ZIP Utility application.
3. Select files or a ZIP archive.
4. Choose the available ZIP operation.
5. Save the processed files.
