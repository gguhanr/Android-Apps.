# 📝 Text to All Text

**Text to All Text** is a simple text and file conversion application that allows users to create, edit, clean, format, and convert text files.


📱 **Android APK Version:** Available as an Android application.

---

## 📱 Android APK

The project is also available as an **Android APK application**.

The APK provides the same main features as the web version in a mobile-friendly interface.

### APK Features

- 📝 Text editor
- 📂 File upload
- 🔄 Text conversion
- ✨ Text formatting
- 🔠 Uppercase / Lowercase
- 🧹 Remove extra spaces
- 🧹 Remove empty lines
- 🔍 Find and Replace
- 💾 Save and Download files
- 🌐 HTML preview
- 📱 Mobile-friendly interface

---

## 📁 Supported File Types

- `.txt`
- `.md`
- `.json`
- `.js`
- `.css`
- `.html`
- `.c`
- `.py`

---

## 🚀 How to Use the APK

1. Download the APK.
2. Install it on your Android device.
3. Open **Text to All Text**.
4. Select or enter your text.
5. Edit and format the content.
6. Select the required file type.
7. Save or download the converted file.

---

## 🎯 Project Purpose

The purpose of this application is to provide an easy-to-use tool for students, developers, and general users to work with different text and code file formats from both **web browsers and Android devices**.
