# 📱 QR Code Generator – Android App

A simple, fast, and modern **QR Code Generator Android App** that allows users to create QR codes from **Text, URLs, Wi-Fi, Email, and Contact information**.

The app provides an easy-to-use interface with QR customization and download/share options.

---

## 📲 App Overview  

**QR Code Generator** is an Android application designed to generate QR codes quickly from different types of information.

Users can enter their data, generate a QR code instantly, customize it, and save or share the generated QR code.

---

## ✨ Features

### 🔗 URL QR Code
Generate a QR code from any website URL.

Example:

```text
https://github.com/
```

### 📝 Text QR Code
Convert any text or message into a QR code.

Example:

```text
Hello! Welcome to my QR Code Generator.
```

### 👤 Contact QR Code
Create QR codes containing contact and business-card information.

### 📶 Wi-Fi QR Code
Generate a QR code containing Wi-Fi network information for easy sharing.

### 📧 Email QR Code
Create QR codes containing email information.

## 📦 Installation

### Option 1 – Download APK

Download the latest APK from the **GitHub Releases** section.

```text
Releases → Latest Version → Download APK
```

Install the APK on your Android device.

> Enable installation from unknown sources if required by your Android device.

### Option 2 – Build from Source

Clone the repository:

```bash
git clone https://github.com/your-username/qr-code-generator.git
```

Open the project in **Android Studio**.

Then:

```text
Build → Build APK(s)
```

Install the generated APK on your Android device.
